# ADR-05062026.1: Adopt Vite + React 19 build toolchain for the wheel demo

Status: proposed

## Context
The app was a single static index.html with vanilla JS and no build step,
served as a hand-written file. SC-134 rewrites it into React for feature
parity, and React requires a build toolchain. No deployment is in scope.

## Decision
Use Vite + React 19 (latest stable; Create React App is sunset). The root
index.html becomes the Vite entry, feature logic moves into components/hooks,
styles port verbatim into a stylesheet, and the build emits to dist/. CI runs
the build rather than asserting a hand-written index.html.

## Consequences
Adds Node/npm, a lockfile, node_modules, and a build step to a previously
build-less repo — contributors now need Node to run or build the app. Trade-off
accepted: React/Vite ergonomics over the zero-tooling simplicity of a single
static file, on the expectation the app grows beyond a static page.
